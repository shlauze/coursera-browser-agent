Coursera Browser Agent 0.2.85 — локальная сборка Windows x64

В репозитории опубликованы исходники 0.2.85. Эта публикация не выпускает
новый EXE. Файлы в GitHub Releases могут иметь более раннюю версию:
https://github.com/shlauze/coursera-browser-agent/releases

СБОРКА ИЗ ИСХОДНИКОВ

Нужны Windows x64, Python с командой py и интернет для установки зависимостей.
Откройте PowerShell в папке browser-agent-v2 и выполните:

  .\build_exe.cmd

Скрипт создаёт .build-venv, устанавливает requirements-build.txt,
собирает dist\CourseraAgent-0.2.85.exe и выполняет его --self-test.
Сборка локальная: скрипт не публикует релиз.

ЗАПУСК СОБРАННОГО EXE

Python устанавливать на целевом компьютере не требуется.
Нужны Google Chrome, интернет, собственный аккаунт Coursera и ключ Groq.

1. Поместите CourseraAgent-0.2.85.exe в отдельную доступную для записи папку.
2. Запустите EXE двойным щелчком. При первом запуске введите ключ Groq
   в консоли (ввод скрыт), либо нажмите Enter для настройки позднее.
3. Панель откроется по адресу http://127.0.0.1:8766/.
4. Нажмите «Запустить». При необходимости войдите в отдельном Chrome.
   Если исполнитель остановился из-за отсутствия входа, запустите его снова.
5. Оставляйте консоль открытой. Для завершения остановите исполнитель,
   дождитесь состояния «Остановлен», затем нажмите Ctrl+C в консоли.

EXE содержит Python и Playwright. Chrome устанавливается отдельно.
Первый запуск может занять время на распаковку компонентов.
build_exe.cmd не подписывает EXE сертификатом издателя.

КОМАНДЫ ИЗ ПАПКИ С EXE

  .\CourseraAgent-0.2.85.exe --version
  .\CourseraAgent-0.2.85.exe --self-test
  .\CourseraAgent-0.2.85.exe configure-groq
  .\CourseraAgent-0.2.85.exe status
  .\CourseraAgent-0.2.85.exe stop

--self-test проверяет комплект локально, без запросов к Coursera/Groq
и без открытия браузерных вкладок.

Запуск исполнителя без новой панели:
  .\CourseraAgent-0.2.85.exe run

Другие локальные порты:
  .\CourseraAgent-0.2.85.exe --chrome-port 9225 serve --panel-port 8767

При явной команде serve откройте http://127.0.0.1:8767/ самостоятельно.
Исполнитель запускается по кнопке; автоматического запуска Windows нет.

ДАННЫЕ И ОБНОВЛЕНИЕ

Прогресс, настройки, зашифрованный ключ, профиль Chrome и журналы находятся
в data, profile и logs рядом с EXE. Сохраняйте их при обновлении своей
установки. Не передавайте эти папки другим пользователям.

Перед заменой EXE остановите исполнитель, дождитесь control_state: stopped
в status, закройте старую панель и сделайте личную резервную копию.
Ключ DPAPI связан с пользователем Windows; на новом компьютере или под
другим пользователем настройте собственный ключ заново.

Одна установка допускает одного исполнителя. Не запускайте разные копии
на одном CDP-порту: подключение может использовать уже открытый профиль.

Groq — единственный провайдер. Перезапуск не отменяет Retry-After;
автоматического переключения ключей нет. Неопределённая отправка требует
сверки с Coursera, а не удаления базы и повторного Submit.

Подробности: README.md и SETUP_OTHER_USER.md в папке browser-agent-v2.
