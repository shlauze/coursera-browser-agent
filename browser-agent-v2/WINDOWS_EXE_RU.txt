Coursera Browser Agent 0.2.58 — Windows x64

Python устанавливать не нужно. Нужны Google Chrome, Интернет,
собственный аккаунт Coursera и ключ Groq.

1. Поместите CourseraAgent-0.2.58.exe в отдельную доступную для записи папку.
2. Запустите EXE двойным щелчком. При первом запуске введите ключ Groq
   в консоли (ввод скрыт), либо нажмите Enter и настройте его позднее.
3. Панель откроется в браузере. Исполнитель запускается кнопкой в панели.
4. Оставляйте консоль открытой. Для выхода используйте Ctrl+C.

Данные, прогресс, профиль и зашифрованный ключ хранятся в папках data,
profile и logs рядом с EXE. Сохраняйте их при обновлении и не передавайте
другим людям. Замена EXE не требует удаления этих папок.

Настройка ключа позднее (из терминала в папке программы):
  .\CourseraAgent-0.2.58.exe configure-groq

Проверка комплекта без запросов к Coursera/Groq:
  .\CourseraAgent-0.2.58.exe --self-test

Если стандартные порты заняты другой установкой:
  .\CourseraAgent-0.2.58.exe --chrome-port 9225 serve --panel-port 8767
  Затем откройте http://127.0.0.1:8767/

Не запускайте новую копию одновременно с другой установкой на том же
CDP-порту. Для переноса существующего прогресса остановите старый
исполнитель и сделайте резервную копию перед переносом своих data/profile.
Ключ DPAPI привязан к пользователю Windows: на новом ПК настройте свой ключ.

Это переносимый EXE без установщика, со встроенными Python и Playwright.
Первый старт может занять несколько секунд на распаковку компонентов.
EXE не подписан сертификатом издателя. Не отключайте защиту Windows.
