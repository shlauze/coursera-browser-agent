# Coursera Browser Agent v2 — 0.2.42

Локальный инструмент для Windows: отдельный профиль Chrome, панель управления,
SQLite с прогрессом и интеграция с Groq. Сертификат считается подтверждённым
только после проверки страницы Coursera с точным названием курса.

## Установка и перенос

Полная инструкция: [настройка для другого пользователя](SETUP_OTHER_USER.md).

```powershell
.\setup.cmd
.\configure_groq.cmd
.\run.cmd
```

`run.cmd` открывает панель без автоматического запуска исполнителя.
По умолчанию панель: http://127.0.0.1:8766/; отдельный Chrome CDP: 9224.
Вход в Coursera выполняется вручную в отдельном профиле.

## Последние изменения

- **0.2.42:** ограниченное ожидание idle после подключения ядра Jupyter;
  проверка неизменности ноутбука, без запуска или прерывания ячеек во время ожидания.

- **0.2.41:** ожидание доступной Launch lab до 30 секунд, однократный запуск
  и отдельная диагностика загрузки Jupyter; готовый редактор не перезапускается.

- **0.2.40:** учёт входных, выходных и суммарных токенов Groq по дням UTC+5
  и курсам в панели и `/api/status` (`groq_usage`). Данные сохраняются в SQLite
  после каждого ответа API, включая ответы с ошибками разбора. Запросы без `usage`
  отмечаются как неизвестный расход; кэш не увеличивает счётчик запросов.
  Исторический расход до установки не восстанавливается. Промпты и ответы в таблицу
  расхода не записываются. Изменение панели вступает в силу после её перезапуска;
  `run.cmd` запускает панель без автоматического запуска исполнителя.

- **0.2.39:** одна сверка страницы для нескольких незавершённых действий;
  повторное использование структуры курса; доступные курсы раньше известных блокировок.
- **0.2.38:** сохранение блокировок отдельных заданий между запусками до появления
  исходного текста или файла; временные ошибки остаются доступны для повторной проверки.
- **0.2.37:** чтение критериев эссе, ограничения объёма и условий peer-review;
  проверка полноты черновика оценки. Автоматическая отправка peer-review не реализована.
- **0.2.35–0.2.36:** обработка My submission, файловых форм и разбора пустой загрузки;
  ошибка отдельного задания не мешает переходу к другим обязательным заданиям.
  Для загрузки требуется явно назначенный локальный файл с проверкой контрольной суммы.

- **0.2.34:** ограниченные повторы чтения при перерисовке и таймаутах;
  восстановление маркера структуры курса; неопределённые тренировочные
  отправки сохраняются, но не блокируют обязательные задания.
  Случайный ответ при дублирующихся вариантах доступен только по явному разрешению.


- **0.2.34:** распознавание окна Start new attempt с вариантами time/timer и таймером; проверка состояния задания перед повторным открытием попытки.

- **0.2.30:** поиск сертификата на странице курса и в разделе Certificates,
  включая пагинацию; проверка точного названия; пропуск подтверждённых курсов.
- **0.2.29:** отображение причины и срока ожидания Groq; сохранение этапов
  получения, заполнения и отправки ответа; сверка неопределённой отправки.
- **0.2.28:** постоянный кэш ответов до заполнения формы. При неизменных
  вопросе, вариантах, модели, контексте и разборе ответ используется без Groq.
- Предыдущие изменения: разбор неудачных попыток перед повтором, защита от
  второго исполнителя, приоритет обязательных экзаменов, отдельный учёт
  неподдерживаемых заданий, подтверждение результатов по отметкам Coursera.

## Ограничения

Не все редакторы и лабораторные поддерживаются. Неопределённый результат,
неизвестное подтверждение или недостаток данных требуют ручной проверки.
Скрипт не гарантирует правильность ответа или получение сертификата.
Не подтверждайте авторство чужой или сгенерированной работы как собственной;
соблюдайте условия курса. Пропуск видео не создаёт ложных отметок завершения.

Лимиты Groq соблюдаются: перезапуск не восстанавливает квоту.
Незавершённые отправки не повторяются без сверки с Coursera.

## Тесты

```powershell
.\run_tests.cmd
```

Тесты используют временные базы, моки и локальные браузерные фикстуры.
Дополнительные зависимости для notebook-фикстур: `requirements-dev.txt`.
Профильная проверка 0.2.30: 47 тестов; 0.2.29: 73 теста.

## Локальные данные

`data/`, `profile/`, `logs/`, `backups/`, `.env` и `.venv/` исключены из Git.
Новый пользователь должен использовать собственные аккаунты и чистую базу.
Не включайте ключи, cookies, ответы, историю попыток или сертификаты в коммиты.

Код: `v2/`; тесты: `tests/`; команды CLI: `python -m v2.cli --help`.
