# Coursera Browser Agent v2 — 0.2.32

Локальный инструмент для Windows: отдельный профиль Chrome, панель управления,
SQLite с прогрессом и интеграция с Groq. Сертификат считается подтверждённым
только после проверки страницы Coursera с точным названием курса.

## Установка и перенос

Полная инструкция: [настройка для другого пользователя](SETUP_OTHER_USER.md).

```powershell
.\setup.cmd
.\configure_groq.cmd
.\run.cmd
```

`run.cmd` открывает панель без автоматического запуска исполнителя.
По умолчанию панель: http://127.0.0.1:8766/; отдельный Chrome CDP: 9224.
Вход в Coursera выполняется вручную в отдельном профиле.

## Ограничения

Не все редакторы и лабораторные поддерживаются. Неопределённый результат,
неизвестное подтверждение или недостаток данных требуют ручной проверки.
Скрипт не гарантирует правильность ответа или получение сертификата.
Не подтверждайте авторство чужой или сгенерированной работы как собственной;
соблюдайте условия курса. Пропуск видео не создаёт ложных отметок завершения.

Лимиты Groq соблюдаются: перезапуск не восстанавливает квоту.
Незавершённые отправки не повторяются без сверки с Coursera.

## Тесты

```powershell
.\run_tests.cmd
```

Тесты используют временные базы, моки и локальные браузерные фикстуры.
Дополнительные зависимости для notebook-фикстур: `requirements-dev.txt`.
Профильная проверка 0.2.30: 47 тестов; 0.2.29: 73 теста.

## Локальные данные

`data/`, `profile/`, `logs/`, `backups/`, `.env` и `.venv/` исключены из Git.
Новый пользователь должен использовать собственные аккаунты и чистую базу.
Не включайте ключи, cookies, ответы, историю попыток или сертификаты в коммиты.

Код: `v2/`; тесты: `tests/`; команды CLI: `python -m v2.cli --help`.
