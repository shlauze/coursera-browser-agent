# Coursera Browser Agent

![Исходники 0.2.87](https://img.shields.io/badge/source-0.2.87-2563eb)
![Windows x64](https://img.shields.io/badge/platform-Windows%20x64-0078d4)
![Groq](https://img.shields.io/badge/LLM-Groq-f55036)

Локальный браузерный агент для работы с очередью курсов Coursera: читает **My Learning → In Progress**, обрабатывает поддерживаемые тесты, задания и лабораторные, сохраняет состояние и показывает ход выполнения в русскоязычной панели.

Текущая реализация находится в **[browser-agent-v2/](browser-agent-v2/)**. Она использует отдельный профиль Google Chrome, Playwright, SQLite и Groq. Видео, лекции и другие учебные материалы исключены из текущего режима выполнения; отметки об их завершении не добавляются.

## Возможности

- **Управление очередью:** запуск, пауза, продолжение, штатная остановка и пропуск курса.
- **Сохранение работы:** прогресс, черновики ответов, причины ручной проверки и журнал намерений отправки сохраняются в SQLite.
- **Поддерживаемые задания:** распознанные формы тестов, отдельные сценарии peer review и файловых заданий, graded Python labs в classic Jupyter.
- **Видимый ход выполнения:** текущая операция, выполнение ячеек, события, расход токенов и наблюдаемые лимиты Groq.
- **Проверка результата:** отправка формы и запуск ноутбука сами по себе не считаются зачётом. Завершение курса требует подтверждённой страницы сертификата с совпадающим названием курса.

Поддержка зависит от конкретной формы и окружения Coursera. Неизвестный интерфейс, неподдерживаемое задание или неопределённый результат сохраняются для проверки пользователем.

## Быстрый старт

Нужны Windows x64, Google Chrome, Python с командой `py` (окружение проекта — Python 3.14), интернет, собственные аккаунты Coursera и Groq. Для клонирования нужен Git; альтернативно распакуйте исходники через **Code → Download ZIP**.

В PowerShell:

```powershell
git clone https://github.com/shlauze/coursera-browser-agent.git
cd .\coursera-browser-agent\browser-agent-v2
.\setup.cmd
.\.venv\Scripts\python.exe -X utf8 -m v2.cli configure-groq
.\run.cmd
```

Ключ вводится скрыто и сохраняется с шифрованием Windows DPAPI. Откройте [локальную панель](http://127.0.0.1:8766/), затем нажмите **«Запустить»**. В отдельном окне Chrome войдите в Coursera вручную, если потребуется. Если запуск остановился из-за отсутствия входа, после входа запустите исполнитель повторно.

`run.cmd` запускает только панель. Исполнитель начинает работу по кнопке. Оставляйте терминал открытым и запускайте только одного исполнителя для одной базы и профиля. Для предварительного входа без выполнения заданий см. [пошаговую настройку](browser-agent-v2/SETUP_OTHER_USER.md).

## Основные команды

Все команды выполняются из `browser-agent-v2/`. Общий префикс:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m v2.cli --help
```

| Команда после `-m v2.cli` | Действие |
| --- | --- |
| `serve` | Панель на `127.0.0.1:8766`, без запуска исполнителя |
| `run` | Один исполнитель без новой панели |
| `scan` | Чтение списка My Learning без открытия задания |
| `status` | Сохранённое состояние в JSON |
| `pause` / `resume` | Пауза / продолжение работающего исполнителя |
| `stop` | Запрос штатной остановки |
| `skip COURSE_ID` / `unskip COURSE_ID` | Исключить курс / вернуть его в очередь |
| `configure-groq` | Сохранить собственный ключ Groq |
| `check-groq` | Проверить ключ реальным тестовым запросом к Groq |

После `stop` дождитесь `"control_state": "stopped"` в `status`. Новый запуск выполняется через `run` или кнопку панели; `resume` предназначен только для паузы.

## Ограничения и сохранность данных

- **Groq — единственный LLM-провайдер.** Ollama и автоматического переключения провайдеров или ключей нет. HTTP 429 учитывает `Retry-After`; срок ожидания сохраняется после перезапуска.
- **Отправки сверяются с Coursera.** После прерывания неопределённая отправка не повторяется автоматически. Не удаляйте базу ради обхода ожидания или повторной отправки.
- **Личные подтверждения требуют внимания.** В чистой базе автоматическое подтверждение Coursera выключено. Пользователь сам проверяет условия и подтверждение авторства.
- **Неизвестные диалоги могут требовать ручной проверки.** Распознанный опрос качества перевода Pendo закрывается без рейтинга или ответа; изменённая разметка остаётся на проверку.
- **Пропуск заданий настраивается отдельно.** Programming Assignment и Upload File не исключаются по умолчанию. Пользовательские исключения не создают зачёт и могут препятствовать получению сертификата.
- **Данные остаются в установке, запросы модели уходят в Groq.** Текст задания и необходимый контекст передаются выбранной модели. Не публикуйте базу, профиль Chrome, ключи или необработанные журналы.
- **Панель и CDP локальные:** порты по умолчанию `8766` и `9224`. Для другой установки используйте отдельные порты. Подключение к уже занятому CDP-порту может использовать существующий профиль Chrome.

## Устройство проекта

```text
browser-agent-v2/
├── v2/
│   ├── cli.py, dashboard.py         # Команды и локальная панель
│   ├── runner.py, control.py        # Очередь и управление исполнителем
│   ├── browser.py, outline.py       # Chrome и чтение страниц
│   ├── assessments.py, notebooks.py # Формы заданий и Jupyter
│   ├── groq_client.py               # Запросы модели и повторные попытки
│   └── store.py                     # SQLite и журнал действий
├── tests/                          # Регрессионные проверки
├── setup.cmd, run.cmd, run_tests.cmd
└── build_exe.cmd, windows_launcher.py
```

Корневые Python-модули и команды относятся к предыдущей реализации: [README_LEGACY.md](README_LEGACY.md). Для новой установки используйте `browser-agent-v2/`.

## Проверка и сборка

Из `browser-agent-v2/`:

```powershell
.\run_tests.cmd
.\build_exe.cmd
```

Тесты используют временные базы, моки и локальные браузерные страницы. Частям набора нужны установленный Chrome и дополнительные зависимости; подробности — в [руководстве](browser-agent-v2/README.md#проверка-кода).

Сборка создаёт локальный `dist\CourseraAgent-0.2.87.exe` и запускает его автономную проверку. Она не публикует GitHub Release. [Инструкция для EXE](browser-agent-v2/WINDOWS_EXE_RU.txt) описывает запуск и сохранение данных.
